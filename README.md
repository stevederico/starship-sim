# Starship Sim

Orbital view of a Block 2 Starship. Three.js + React. Textures from Grok Imagine. Earth from NASA Blue Marble.

## Run

```bash
bun install
bun run dev
```

Open http://127.0.0.1:5173/

- Drag to orbit
- Scroll to zoom
- Space or **Ignite** for a Raptor burn

## Stack

React 19, Vite, Tailwind v4, Three.js, React Three Fiber.

Ship is 52.1 m × 9 m (Block 2). Earth is cinematic scale so the vehicle stays visible.
